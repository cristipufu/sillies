# Woof reference outputs

Voice by [Underdog Woof](https://underdog.ai).

These two synthetic utterances were generated by the publisher's NumPy runtime from the pinned model
revision, with seed zero. `provenance.json` records the input, versions, revision and file hashes.
They are little-endian Float32 mono PCM at 24 kHz. They are test data, not models or app resources.
The model and generated audio remain under the Underdog Non-Commercial License 1.0; see
[the retained license and notices](../../../../THIRD_PARTY_NOTICES.md).

Run the opt-in CPU/GPU and cancellation checks with `SILLIES_WOOF_MODEL` pointing at the installed
pinned model directory. The fixtures are bundled with the tests, so Python is not needed to run them.
Ordinary checks never download weights or open an audio device.
